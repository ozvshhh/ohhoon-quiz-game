# 오훈 교수님의 질문 공격

오훈 교수님의 **컴퓨터구조(MIPS)** 강의에서 컴공과 이하은이 살아남는 반응속도 게임.

- 교수님이 주기적으로 질문을 던진다. `SPACE` 로 대답.
- 대답을 안 하면 교수님 얼굴이 빨개진다 → 터지면 게임 오버.
- 대답하면 교수님이 뒷자리로 온다. 주변 학생들이 열심히 듣는 척하며 얼굴이 빨개지고,
  교수님이 앞으로 돌아가면 이하은을 노려본다 → 터지면 게임 오버.
- 질문 주기는 계속 짧아진다. 얼마나 버티는지가 점수.

단일 HTML 파일(`index.html`)이라 그냥 열면 바로 실행된다.

## 랭킹 서버 연결 (선택)

`index.html` 안의 `RANK_URL` 에 Firebase Realtime Database URL 을 넣으면
로그인 없이 누구나 기록을 등록하는 공개 랭킹이 켜진다. 비워두면 브라우저 로컬 기록만 사용한다.
